# Snake

C言語でオブジェクト指向を実現する方法を学ぶための
Windows コンソール向けサンプルです。

## 何が学べるか

C言語には class というキーワードがありません。構造体にはメンバ関数を定義できません。継承の構文もありません。
しかし、構造体と関数ポインタを組み合わせれば、C++のクラスに近い設計が実現できます。

## ビルド

GCC と make を用意して、プロジェクトのディレクトリで実行します：

```bash
make
```
